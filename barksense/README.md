# BarkSense

On-device dog vocalization classifier on the XIAO ESP32S3 Sense. All inference
runs on the microcontroller — audio never leaves the device.

**Pipeline:** PDM mic → 1-second buffer → on-chip log-mel(40) + Δ + ΔΔ (120×61
int8) → DS-CNN (TFLite Micro, α=1.0 INT8) → argmax → per-class response

**Classes (4):** `bark`, `growl`, `grunt`, `ambient`. Human speech is *folded
into ambient* at training time, so people talking reads as "not a dog event"
rather than a false bark.

**Per-class responses** (see `firmware/src/main.cpp`):

| Class | Action |
|---|---|
| `bark` | ntfy.sh push notification + LED blink (60 s cooldown) |
| `growl` | play `/owner_voice.wav` over the speaker + LED solid (10 s cooldown) |
| `grunt` | append a line to `/events.log` on LittleFS |
| `ambient` | no-op |

## Layout

```
barksense/
  data/
    bark/dog_{bark,growl,grunt}_{train,test}/  Pre-split dog clips, 16 kHz mono
    ambient_{train,test}/  (or ambient/)       Background / non-dog audio
    human/                                      Speech — folded into ambient
  scripts/
    preprocess.py              Slice, balance, extract log-mel+Δ+ΔΔ → train/val/test.npz
    compress_sweep.py          Train DS-CNN α-sweep, convert f32+INT8, eval, tradeoff plot
    convert.py                 Export chosen .tflite → C array + norm params
    export_test_feature.py     Generate firmware test fixtures + mel/delta kernel headers
    simulate_mcu_features.py   Host-side NumPy reimpl of the MCU DSP (parity check)
    validate_tflite.py         Re-check a shipped .tflite against the test set
  notebooks/
    train.ipynb                DS-CNN definition, training, evaluation (exploratory)
  model/                       .h5 / .keras, .tflite, sweep results, .npz splits (gitignored)
  firmware/                    PlatformIO project (XIAO ESP32S3 Sense)
    src/main.cpp               Audio capture, DSP, inference, action dispatch
    src/model_data.cc          TFLite model byte array (generated by convert.py)
    include/config.h           Hardware pins, class enum, gating + cooldown constants
    include/secrets.h          WiFi + ntfy credentials (gitignored)
    include/norm_params.h      MFCC z-score params         (generated by convert.py)
    include/mel_filterbank.h   Slaney mel matrix (40×257)  (generated by export_test_feature.py)
    include/delta_kernels.h    Savitzky-Golay delta kernels (generated by export_test_feature.py)
    include/test_data.h        Embedded FEATURE_TEST fixture (generated by export_test_feature.py)
    data/owner_voice.wav       Played on `growl`; uploaded to LittleFS
    partitions.csv             4 MB app + 4 MB LittleFS
  presentation/                Poster + write-up
```

## Setup

```bash
pip install -r requirements.txt
cp firmware/include/secrets.h.example firmware/include/secrets.h
# then edit secrets.h with your WiFi credentials and ntfy topic
```

## Workflow

### 1 — Collect clips

Dog clips go in `data/bark/dog_{bark,growl,grunt}_{train,test}/` (pre-split into
train/test). Background audio goes in `data/ambient_{train,test}/` (or a single
`data/ambient/` that gets split 80/20). Speech goes in `data/human/` — it is
folded into the ambient class.

Aim for ≥ 100 clips per class. Good free sources: [FreeSound](https://freesound.org),
ESC-50. `preprocess.py` slices everything into non-overlapping 1 s segments,
down-samples ambient and up-augments the rare classes (growl/grunt/human) toward
a balanced training set (val/test are left untouched).

### 2 — Preprocess

```bash
python scripts/preprocess.py
# → model/train.npz, model/val.npz, model/test.npz, model/norm_stats.npz
```

### 3 — Train & sweep

```bash
python scripts/compress_sweep.py
# → model/sweep_a*.tflite (float32 + INT8), model/sweep_results.json, tradeoff plot
```

`compress_sweep.py` trains the DS-CNN, converts each α to float32 and INT8
TFLite, evaluates on the test set, and reports size / arena / macro-F1 per
config. `notebooks/train.ipynb` covers the same model interactively if you want
to inspect training curves. Current ship target: **α=1.0 INT8** — ~64 KB flash,
~1.8 MB arena.

### 4 — Export to C

```bash
python scripts/convert.py model/sweep_a1.0_int8.tflite
# → firmware/src/model_data.cc        (model byte array)
# → firmware/include/norm_params.h    (z-score params from norm_stats.npz)
```

Then regenerate the DSP kernel headers (mel filterbank, delta kernels) and the
embedded self-test fixture:

```bash
python scripts/export_test_feature.py
# → firmware/include/{mel_filterbank.h, delta_kernels.h, test_data.h}
```

### 5 — Flash

```bash
cd firmware
pio run --target upload          # firmware
pio run --target uploadfs        # owner_voice.wav → LittleFS
pio device monitor
```

The boot log prints `[ready] arena X / Y bytes` — use it to confirm the arena
fits and trim `kTensorArenaBytes` if you want the SRAM/PSRAM headroom back.

## Configuration

| File | What to edit |
|---|---|
| `firmware/include/secrets.h` | WiFi SSID/password, ntfy topic URL |
| `firmware/include/config.h` | gating thresholds, cooldowns, arena size, GPIO pins |

Key constants in `config.h`:

| Constant | Default | Purpose |
|---|---|---|
| `kActionMinConfidence` | `0.75` | Min top-class softmax to act on bark/growl/grunt |
| `kActionMinMargin` | `0.25` | Min gap between top-1 and top-2 |
| `kDogEventMinTotal` | `0.85` | Combined dog-class mass that counts as a dog event |
| `kSilenceRms` | `150` | Loudness gate — clips quieter than this are no-events |
| `kNotifyCooldownMs` | `60 s` | ntfy POST cooldown |
| `kPlayCooldownMs` | `10 s` | owner-voice playback cooldown |
| `kTensorArenaBytes` | `3 MB` | TFLite arena (lives in PSRAM) |

## ntfy.sh

1. Install the [ntfy app](https://ntfy.sh) (iOS / Android / web)
2. Pick a unique topic name (e.g. `barksense-yourname-99`)
3. Subscribe in the app
4. Set `kNtfyUrl = "https://ntfy.sh/<your-topic>"` in `secrets.h`

## Hardware

XIAO ESP32S3 Sense (8 MB flash, 8 MB PSRAM). Built-in PDM mic on I2S0. Optional
MAX98357A speaker on I2S1 for the `growl` owner-voice response:

| MAX98357A | XIAO pin | GPIO |
|---|---|---|
| BCLK | D0 | 1 |
| LRC / WS | D1 | 2 |
| DIN | D2 | 3 |

## Build-flag self-tests

Uncomment in `firmware/platformio.ini`:

- `-DFEATURE_TEST` — runs the on-chip DSP once against the Python-generated
  fixture in `test_data.h` (bit-exact MCU↔host parity), then halts.
- `-DAUDIO_TEST` — plays `/owner_voice.wav` once at boot and halts (verifies
  LittleFS + RIFF parse + I2S1 + speaker wiring).

`scripts/simulate_mcu_features.py` reproduces the MCU feature pipeline in NumPy
and `scripts/validate_tflite.py` re-checks the shipped model — both catch
mismatches before flashing.

## Tuning

| Symptom | Fix |
|---|---|
| Low bark recall | Lower `kActionMinConfidence` / `kActionMinMargin`, add bark clips |
| Too many false positives | Raise thresholds, add more ambient/human clips |
| Speech triggers a dog class | Add the offending audio to `data/human/` and retrain |
| Quiet-room false triggers | Raise `kSilenceRms` |
| `AllocateTensors failed` | Increase `kTensorArenaBytes` (check the boot-log arena estimate) |
| Firmware too large | Sweep a smaller α and re-export |
