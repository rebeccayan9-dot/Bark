# BarkSense

On-device dog bark detector on XIAO ESP32S3 Sense.

**Pipeline:** PDM mic → 1-second buffer → on-device MFCC → DS-CNN (TFLite Micro) → ntfy.sh alert

## Layout

```
barksense/
  data/{bark,human,ambient}/  Raw .wav clips — 16 kHz mono, 1 second each
  scripts/
    preprocess.py             Extract MFCCs, save train/val/test splits
    compress.py               Sweep width multipliers × quantization
    convert.py                Export .tflite + norm params to C headers
  notebooks/
    train.ipynb               DS-CNN definition, training, evaluation
  model/                      .h5, .tflite, sweep results (gitignored)
  firmware/                   PlatformIO project (XIAO ESP32S3 Sense)
    src/main.cpp              Audio capture, DSP, inference, alerting
    include/config.h          DSP + inference constants
    include/secrets.h         WiFi + ntfy credentials (gitignored)
    include/norm_params.h     MFCC z-score params (generated by convert.py)
    include/model_data.h      TFLite model array header
```

## Setup

```bash
pip install -r requirements.txt
```

Edit `firmware/include/secrets.h` with your WiFi credentials and ntfy topic.

## Workflow

### 1 — Collect clips

Add 1-second `.wav` files to `data/bark/`, `data/human/`, `data/ambient/`.
Aim for ≥ 100 clips per class; 300+ for good generalisation.

Good free sources: [FreeSound](https://freesound.org), ESC-50 dataset.

### 2 — Preprocess

```bash
python scripts/preprocess.py
# → model/features.npz
```

### 3 — Train

```bash
jupyter notebook notebooks/train.ipynb
```

Run all cells. Saves `model/ds_cnn_a1.0_float32.h5` and a float32 baseline TFLite.

### 4 — Sweep & pick a model

```bash
python scripts/compress.py
# → model/sweep_results.json
# → model/tradeoff.png
# → model/ds_cnn_a{1.0,0.75,0.5}_{f32,int8}.tflite
```

Target: ≤ 96 KB RAM, ≤ 400 KB flash. The α=0.75 INT8 variant is a good starting point.

### 5 — Export to C

```bash
python scripts/convert.py model/ds_cnn_a0.75_int8.tflite
# → firmware/src/model_data.cc   (byte array)
# → firmware/include/norm_params.h  (z-score params)
```

### 6 — Flash

```bash
cd firmware
pio run --target upload
pio device monitor
```

## Configuration

| File | What to edit |
|---|---|
| `firmware/include/secrets.h` | WiFi SSID/password, ntfy topic URL |
| `firmware/include/config.h` | `kBarkThreshold` (default 0.70), `kCooldownMs` (60 s), `kTensorArenaBytes` |

## ntfy.sh

1. Install the [ntfy app](https://ntfy.sh) (iOS / Android / web)
2. Pick a unique topic name (e.g. `barksense-yourname-99`)
3. Subscribe in the app
4. Set `kNtfyUrl = "https://ntfy.sh/<your-topic>"` in `secrets.h`

## Tuning

| Symptom | Fix |
|---|---|
| Low bark recall | Lower `kBarkThreshold` |
| Too many false positives | Raise threshold, or add more human/ambient clips |
| `AllocateTensors failed` | Increase `kTensorArenaBytes` (check compress.py RAM estimate) |
| Firmware too large | Use α=0.5 INT8 variant |
